# ADVISER

Персональный сайт ADVISER — «Связь. Код. Результат.»

## Направления

- **Voice** — коммуникации, VoIP, Cisco, SIP и интеграции.
- **Vibe-Coding** — автоматизация, скрипты, боты и веб-инструменты с использованием современных технологий и ИИ.
- **Trader** — алгоритмические стратегии, исследования, бэктесты, автоматизация и работа с торговыми данными.

## Публикация

Сайт публикуется через GitHub Pages из ветки `main`.
